# Bike Sharing Network Analysis

This project studies and compares bike-sharing station networks in Oslo and Helsinki using tools from social network analysis.
Trips are modeled as a directed, weighted graph where nodes are stations and edges represent flows between stations (weighted by trip counts).
The analysis explores structural properties of the networks and highlights similarities and differences between the two cities.

The full methodology and results are documented in the report; the notebook contains the complete processing and analysis pipeline.

## Repository contents

- `bike_sharing_oslo_helsinki.ipynb`: notebook with data processing and analysis code.
- `Bike Sharing Network Analysis Report.pdf`: final project report.
- `requirements.txt`: Python dependencies used for the notebook.
