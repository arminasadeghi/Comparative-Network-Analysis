# Bike Sharing Network Analysis

Network analysis of bike-sharing systems in Oslo and Helsinki.

## Repository contents

- `bike_sharing_oslo_helsinki.ipynb`: notebook with data processing and analysis code.
- `Bike Sharing Network Analysis Report.pdf`: final project report.
- `requirements.txt`: Python dependencies used for the notebook.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Notes

The `Data/` directory is intentionally excluded from version control.
